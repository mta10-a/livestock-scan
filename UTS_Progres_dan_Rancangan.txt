3. FITUR ESENSIAL DAN FITUR YANG DITUNDA
--------------------------------------------------------------
Alur inti yang dibuat:
  Daftar/Login -> Pilih spesies -> Unggah foto -> Hasil
  (penyakit + confidence + peringatan + rekomendasi)
  -> Riwayat, dengan kuota 3x scan gratis.

Ditunda (tampil abu-abu "segera" di aplikasi):
  - Konsultasi dokter hewan (RF-31 s.d. RF-34)
  - E-sertifikat (RF-20 s.d. RF-23)
  - Peta wabah dan laporan wabah (RF-19, RF-24, RF-25)
  - Verifikasi dokter (RF-04, RF-35 s.d. RF-37)
  - Pembelian token dan Payment Gateway (RF-27 s.d. RF-30)
  - Dashboard Admin (RF-38 s.d. RF-40)
  - Lengkapi profil peternakan (RF-03)


4. RANCANGAN TEKNIS
--------------------------------------------------------------
Frontend   : HTML, CSS, JavaScript (tampilan mobile)
Backend    : Node.js + Express, SQLite, bcrypt, JWT, multer
AI Service : Python (Flask) + Pillow + MediaPipe (EfficientNet-Lite0)
             + classifier hasil latihan sendiri dari dataset ternak
Desain     : Figma
Alur       : Browser -> Node.js -> Flask -> Node.js -> Browser

Aturan penting:
  - Jika Flask error, kuota scan TIDAK berkurang.
  - Password disimpan dalam bentuk hash.
  - Foto: hanya JPG/PNG, maksimal 5 MB.
